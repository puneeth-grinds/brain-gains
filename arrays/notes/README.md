## Array - Fundamentals

- Array is a collection of elements stored in a sequence and is identified by an index
```
- Seat No →   1      2      3      4      5
          ┌──────┬──────┬──────┬──────┬──────┐
          │ John │ Mary │ Alex │  --  │ Sara │
          └──────┴──────┴──────┴──────┴──────┘
```
- each element sits next to each other in the memory and are not scattered and this gives you O(1)
